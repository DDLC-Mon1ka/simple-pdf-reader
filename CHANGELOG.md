# Changelog

## 1.8.0

- Added native annotated-PDF export with printable highlights, sticky-note
  annotations, and user bookmarks converted to PDF outline entries.
- The original PDF remains unchanged; the application writes a separate copy.
- Encrypted source documents remain encrypted in the exported copy.

## 1.7.1

- Refined the dark interface, toolbar grouping, spacing, sidebar tabs, and
  window sizing.
- Added a cleaner source distribution and VS Code build configuration.

## 1.7.0

- Added OpenAI-compatible API settings and encrypted API-key storage.
- Added streaming AI summaries and PDF question answering with page citations.

## 1.6.0

- Added local extractive summaries with metadata, keywords, and key sentences.

## 1.5.0

- Added colored highlights, notes, annotation management, search-result lists,
  and Markdown/TXT excerpt export.

## 1.4.0

- Added text selection, user bookmarks, navigation history, dark reading mode,
  and batched thumbnail loading.

## 1.3.0

- Added thumbnail and outline sidebars, internal/external link support, and
  reading progress.

## 1.2.0

- Added full-text search, recent files, reading-position restore, and drag/drop.

## 1.1.0

- Added single-page, two-page spread, and continuous reading views.

## 1.0.0

- Initial Windows PDF reader.
