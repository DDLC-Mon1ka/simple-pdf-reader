简易 PDF 阅读器 1.8

启动：
双击“简易PDF阅读器.exe”。

打开 PDF：
1. 点击左上角“打开 PDF”。
2. 也可以直接把 PDF 拖进阅读器窗口。

常用操作：
- 切换视图：点击工具栏“视图”，可选单页、双页并排或多页连续。
- 侧栏：点击右上角 ☰ 打开或关闭；可切换页面缩略图、PDF 目录和用户书签。
- 用户书签：在“书签”标签点击“+ 当前页”，或按 Ctrl+D。
- 文字复制：按住 Shift 拖动框选文字，再按 Ctrl+C 或右键复制。
- 高亮和便签：框选文字后右键，可选黄色/绿色/蓝色高亮或添加粉色便签。
- 批注管理：侧栏“批注”页可以定位、右键编辑或删除批注。
- 搜索列表：全文搜索完成后会自动切到“搜索”页，双击结果直接跳转。
- 导出摘录：在“批注”页点击“导出”，可保存为 Markdown 或 TXT。
- 导出批注 PDF：在“批注”页点击“导出 → 带批注 PDF”，会把高亮、便签和用户书签写入一份新 PDF，原文件不会改变；加密 PDF 的副本仍会加密，并使用打开原文件时的密码。
- 信息总结：打开“摘要”页并点击“生成”，会提取文档信息、关键词和核心句子；可复制或导出。
- API 设置：在“导航 → API 设置”中填写兼容 OpenAI Chat Completions 的 Base URL、模型和密钥。
- AI 摘要：配置 API 后在“摘要”页点击“AI”。
- 文档问答：在“问答”页输入问题，回答会尝试附上 `[p.页码]` 引用。
- API Key 使用 Windows 用户级加密保存，不会写入普通配置文本。
- 默认不会上传 PDF；只有主动使用 AI 摘要或问答时，相关文字片段才会发送到你自己配置的 API 服务。
- 前进后退：Alt + 左方向键返回，Alt + 右方向键前进。
- 夜间模式：点击工具栏“视图”，勾选“夜间护眼模式”。
- 长 PDF 的缩略图会分批加载，滚动到底部会自动继续。
- 链接：点击 PDF 里的内部链接会跳到目标页，外部网址会用默认浏览器打开。
- 阅读进度：底部蓝条显示当前整份 PDF 的阅读位置。
- 全文搜索：按 Ctrl + F，输入关键词后按 Enter，按 Shift + Enter 查找上一个。
- 续读：重新打开同一文件时，会自动回到上次页码、视图和缩放状态。
- 最近文件：点击工具栏“最近”，可以重新打开最近看过的 PDF。
- 翻页：Page Up / Page Down，或左右方向键。
- 跳到第一页 / 最后一页：Home / End。
- 缩放：Ctrl + 鼠标滚轮，或 Ctrl + 加号 / 减号。
- 适合宽度：Ctrl + 0。
- 拖动页面：按住鼠标左键拖动。
- 全屏：F11，退出全屏按 Esc。
- 快速切换视图：Ctrl + M。

说明：
- 搜索依赖 PDF 自带的文字层；纯扫描图片 PDF 需要先做 OCR 才能搜索。

重要：
- 程序默认在本地运行，不会上传 PDF；只有主动使用 AI 摘要或文档问答时，相关文字片段才会发送到你自己配置的 API 服务。
- 如果 PDF 设置了密码，打开时会提示输入。
- 如果 Windows 拦截了程序，可以选择“更多信息”后核对文件名再运行。
